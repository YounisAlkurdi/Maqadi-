# Maqadi — طلبات البيت

مشروع مشارك في **هاكاثون نمكّن للذكاء الاصطناعي 2026** (22–30 نوفمبر 2026).

موقع ويب عربي (RTL) لمشاركة قائمة طلبات البيت بين أفراد العائلة بدون تسجيل حسابات أو كلمات مرور. الميزة الأساسية تتيح لك لصق رسائل الواتساب المتفرقة ليقوم الذكاء الاصطناعي (مع بديل يعمل بدون AI) باستخراج قائمة منظمة ومصنفة جاهزة للتأكيد.

## التشغيل المحلي

```bash
cd backend && uv sync --extra dev
cp ../.env.example ../.env
cd backend && uv run uvicorn app.main:app --reload
```

افتح `http://localhost:8000` في المتصفح، و`http://localhost:8000/api/v1/healthz` للتحقق من الخادم.
